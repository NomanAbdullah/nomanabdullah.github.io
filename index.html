Introduction

Securing software
from the ground up.

I'm a PhD student in Computer Science at Baylor University, working with Dr. Mengfei Ren on security vulnerabilities introduced at the compiler level — a foundational but often overlooked layer of the software stack.

My research sits at the intersection of compiler design and security engineering, asking: what bugs and vulnerabilities does the compiler itself introduce? I develop static analysis techniques and security-preserving optimizations to catch these issues before they reach production.

Beyond compilers, I explore Generative AI security, IoT threat modeling, and defense-in-depth architectures for critical infrastructure.

Compiler Security Static Analysis Memory Safety LLM Security IoT Protocols DevSecOps Software Verification

Focus Areas

Research

🛡

Software Security

Compiler-based security enhancements for C/C++ programs, novel static analysis techniques for memory safety violations, and security-preserving optimizations that maintain performance without sacrificing robustness.

🔒

Security Engineering

Designing robust security architectures, implementing defense-in-depth strategies, and developing secure system design methodologies for critical infrastructure protection.

🤖

Generative AI Security

Investigating security risks in large language models, developing adversarial attack detection systems, and creating frameworks for secure AI deployment and prompt injection prevention.

🌐

IoT Security

Securing IoT ecosystems, developing lightweight cryptographic protocols for resource-constrained devices, and creating security frameworks for smart home and industrial networks.
